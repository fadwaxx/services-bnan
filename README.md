# موقع مكتب الخدمات الإلكترونية

موقع تعريفي (Static) بالكامل لمكتب خدمات عامة وإلكترونية، مبني بـ React و Vite و
TypeScript و Tailwind CSS و Framer Motion. لا يحتوي على أي Backend أو قاعدة بيانات أو
تسجيل دخول؛ هدفه عرض الخدمات وتحويل العميل إلى واتساب برسالة جاهزة.

## التشغيل

```bash
npm install
npm run dev
```

بعدها افتح الرابط الذي يظهر في الطرفية (عادة `http://localhost:5173`).

### بناء نسخة الإنتاج

```bash
npm run build
npm run preview
```

سينتج مجلد `dist` يحتوي على الموقع الجاهز للرفع على أي استضافة Static (مثل Vercel أو
Netlify أو Cloudflare Pages أو أي استضافة عادية).

## أهم الملفات التي ستحتاج لتعديلها

| الملف | الغرض |
|---|---|
| `src/config/siteConfig.ts` | اسم المكتب، رقم واتساب، ساعات العمل، الموقع، روابط التواصل |
| `src/data/services.ts` | جميع الخدمات (الإضافة والتعديل والحذف تتم من هنا فقط) |
| `src/data/team.ts` | بيانات أعضاء فريق العمل |
| `src/data/projects.ts` | الأعمال والإنجازات السابقة (اتركها مصفوفة فارغة `[]` لإخفاء القسم) |

## إضافة خدمة جديدة

أضف عنصرًا جديدًا داخل مصفوفة `services` في `src/data/services.ts` باتباع نفس الهيكل
الموجود، وحدد له:

- `code`: رمز الخدمة الثابت (مثل `JD-003`)
- `category`: أحد التصنيفات المعرفة في `ServiceCategory`

- `isActive`: اجعلها `false` لإخفاء الخدمة من الموقع دون حذفها
- `isFeatured`: لتمييزها لاحقًا إن احتجت ذلك

الخدمة الجديدة ستظهر تلقائيًا في البحث والتصنيف والبطاقات ونافذة التفاصيل ورسالة واتساب
دون الحاجة لتعديل أي Component.

## تغيير رقم واتساب

عدّل قيمة `whatsappNumber` في `src/config/siteConfig.ts` (بالصيغة الدولية بدون علامة `+`
أو صفر البداية، مثل `9665XXXXXXXX`).

## ملاحظات مهمة

- الموقع لا يرسل أي رسالة تلقائيًا؛ فقط يفتح واتساب برسالة جاهزة، والعميل هو من يضغط زر
  الإرسال.
- لا يوجد أي تخزين لبيانات العملاء داخل الموقع (لا Local Storage ولا Cookies ولا أي
  تخزين آخر).
